## 🔑 Key Features

### 1. Real Data Integration

- ✅ Your MCP server fetches real news via GNews API
- ✅ Tariff announcements from Federal Register
- ✅ Economic data from BEA and Census
- ✅ All data fed to GPT-4 for article generation

### 2. Source References

Every article includes verified sources:

- USDA, BLS, EIA for price data
- Federal agencies for policy data
- News outlets for current events
- All URLs and publish dates stored

### 3. Automated Schedule

- Runs every 2 hours automatically
- Generates 7-8 articles per run
- ~84 articles per day
- No manual intervention needed

### 4. MongoDB Storage

Complete article metadata:

- Title, slug, category, description
- Price info, impact scores, locations
- Chart data for visualizations
- Source references with URLs
- View tracking, tags, timestamps

### 5. Dynamic Frontend

- Fetches articles from API
- Category filtering
- Latest articles shown first
- Source links clickable
- "Generated by AI" badge

## 🔧 Customization

### Change Generation Frequency

Edit `server/index.js`:

```javascript
scheduleArticleGeneration(3); // Every 3 hours instead of 2
```

### Change Article Count

Edit `server/services/articleScheduler.js`:

```javascript
const count = 10; // Generate 10 articles instead of 7-8
```

### Add New Categories

Edit `server/services/articleGenerator.js`:

```javascript
const articleTemplates = [
  {
    category: 'environment',
    icon: '🌱',
    iconBg: '#d1f4dd',
    topics: ['carbon tax', 'emissions', 'green energy'],
  },
  // ...
];
```

## 🎬 What Happens Next

### First Run:

1. MCP server starts → All APIs initialized
2. Node.js server starts → Scheduler begins
3. Scheduler triggers → Calls MCP server
4. MCP server:
   - Fetches latest news about each topic
   - Gets recent tariff announcements
   - Generates article using GPT-4
   - Returns JSON with article data
5. Node.js saves articles to MongoDB
6. Frontend displays articles

### Every 2 Hours After:

- Repeat steps 3-6 automatically
- New articles appear on Insights page
- Old articles remain accessible
